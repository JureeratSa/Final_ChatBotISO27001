เปรียบเทียบข้อจำกัดของระบบค้นหาแบบเดี่ยว vs ระบบ Hybrid Search

1. Dense Vector Search (ChromaDB + BGE-M3)

Semantic Search
✅ จุดเด่น: เข้าใจบริบทและเจตนา แม้ใช้คำไม่ตรงกัน เช่น "ตัดแว่น" โยงไปหา "สวัสดิการสายตา"
❌ จุดอ่อน: ค้นหาคำศัพท์เฉพาะทาง, ตัวย่อ, รหัสเอกสาร (เช่น SPO-2024), หรือชื่อบุคคลได้ไม่แม่นยำ

2. Lexical Search (BM25 + PyThaiNLP)

Keyword Search
✅ จุดเด่น: แม่นยำ 100% กับคำค้นที่ตรงตัว, ชื่อหมวดหมู่, ตัวเลขมาตรา, หรือคำเฉพาะ
❌ จุดอ่อน: ไม่เข้าใจคำพ้องความหมาย หากเอกสารเขียนว่า "ค่ารักษาพยาบาล" แต่ผู้ใช้ถาม "หาหมอ" จะหาไม่เจอ
คุณสมบัติการค้นหา Vector Search อย่างเดียว Keyword Search (BM25) อย่างเดียว Hybrid Search (ระบบของเรา)
ความเข้าใจภาษาพูดธรรมชาติ ดีเยี่ยม (High) ต่ำ (ต้องพิมพ์ตรงคำ) ดีเยี่ยมรอบด้าน ⭐⭐⭐
ความแม่นยำกับชื่อเฉพาะ / รหัสระเบียบ ปานกลาง - หลุดบ่อย ดีเยี่ยม (Exact Match) แม่นยำสูงมาก ⭐⭐⭐
การจัดการคำภาษาไทย / คำติดกัน ขึ้นกับ Tokenizer ของ Model ใช้ PyThaiNLP ตัดคำล่วงหน้า ผสานทั้ง 2 รูปแบบ ⭐⭐⭐
โอกาสดึงเอกสารผิดบริบท มีโอกาสเกิด False Positive พลาดข้อมูลที่เขียนคนละคำ ต่ำที่สุด (กรองผ่าน 2 ชั้น)

กลไกการรวมคะแนนและการปรับจูนประสิทธิภาพ (Tuning)

สูตร Reciprocal Rank Fusion (RRF) แบบถ่วงน้ำหนัก

Score(d) = 0.4 × (1 / (60 + Rank_dense)) + 0.6 × (1 / (60 + Rank_bm25))

• Rank คืออันดับที่เอกสารชิ้นนั้นทำได้ในแต่ละระบบ (อันดับ 1, 2, 3, ...)
• ค่าคงที่ k = 60 ช่วยป้องกันไม่ให้อันดับ 1 มีอิทธิพลโดดจนกลบเอกสารดีอื่นๆ
• การถ่วงน้ำหนัก (60:40): ให้ความสำคัญกับ BM25 0.6 และ Dense 0.4 เพราะเอกสารระเบียบองค์กรต้องการความถูกต้องของคำและเงื่อนไขสูงมาก

ระบบสิทธิประโยชน์บูสท์ (Benefit Keyword Boosting)

ระบบมีกลไกตรวจสอบคำสำคัญในสิทธิประโยชน์เฉพาะ หากพบคำในรายการจะทำการ Boost คะแนนพิเศษ (+0.15) ทันที เพื่อป้องกันข้อมูลตกหล่น:

👓 แว่น / เลนส์ / เลสิก 🦷 ฟัน / ทันตกรรม 💉 วัคซีน / ตรวจสุขภาพ 👟 รองเท้า / กีฬา / ฟิตเนส 💆 นวด / กายภาพบำบัด 💊 ยา / วิตามิน 🦺 หมวกนิรภัย / แมสก์

กระบวนการหลังจากรวมคะแนนเสร็จสิ้น:

1. เรียงลำดับคะแนนรวม: จัดเรียง Chunks ทั้งหมดจากคะแนนสูงสุดลงมา
2. คัดกรอง Top-K (เช่น 5 Chunks): เลือกเฉพาะเนื้อหาที่มีน้ำหนักเกี่ยวข้องจริง
3. แนบ Metadata: พ่วงชื่อไฟล์และหน้าที่มา เพื่อให้ AI แสดง Citations อ้างอิงได้

ตัวอย่างสถานการณ์จริงเปรียบเทียบผลลัพธ์การค้นหา

กรณีที่ 1: ภาษาพูด / คำพ้อง User ถามไม่ตรงกับเอกสาร
คำถาม: "อยากทำเลสิกรักษาตา เบิกเงินช่วยเหลือได้ไหม"

• BM25: อาจหาไม่พบ หากในเอกสารใช้คำว่า "การรักษาความผิดปกติทางสายตาด้วยแสงเลเซอร์"
• Dense Search: เข้าใจความหมายและดึงหมวดสวัสดิการสายตาขึ้นมา
• ผลลัพธ์ Hybrid: ได้ข้อมูลที่ถูกต้องครบถ้วน 100%

กรณีที่ 2: รหัสเฉพาะ / ชื่อระเบียบ User ถามด้วยรหัสหรือคำย่อ
คำถาม: "ตามระเบียบ SPO-2024 หมวด 3 มีเงื่อนไขอย่างไร"

• Dense Search: อาจมองข้ามรหัสเฉพาะเพราะเวกเตอร์คำเฉพาะใกล้เคียงกับระเบียบอื่น
• BM25: ล็อกเป้าหมายคำว่า "SPO-2024" และ "หมวด 3" ได้ตรงเผง
• ผลลัพธ์ Hybrid: ชี้เป้าข้อระเบียบที่ถูกต้องทันที

สรุป 4 ประเด็นสำคัญสำหรับใช้นำเสนอ (Key Takeaways):

1. ทำงานคู่ขนาน: ประมวลผลทั้ง 2 ระบบพร้อมกันทุกครั้งใน 1 คำถาม ไม่ใช่แค่ทางเลือกสำรอง
2. ผสานจุดเด่น: ดึงทั้ง "ความหมายเชิงลึก (Dense)" และ "ความตรงตัวของคำ (BM25)"
3. ปรับแต่งเพื่อองค์กร: มีระบบถ่วงน้ำหนัก 60:40 และ Keyword Boost สำหรับสวัสดิการโดยเฉพาะ
4. ตอบตรง เชื่อถือได้: ป้องกัน AI กุเรื่อง (Hallucination) ด้วยหลักฐานบริบทที่แม่นยำ
