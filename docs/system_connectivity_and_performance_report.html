1.3 มาตรการความปลอดภัยและนโยบายการเชื่อมต่อ (Security & Governance Policies)

  • CORS Policy: ไม่อนุญาต allow_origins=["*"] เด็ดขาด ควบคุมเฉพาะ Origin ที่กำหนด และ Subnet วง LAN รพ. ผ่าน Regex http://192.168.55.*:[0-9]+
  • Rate Limiting: ควบคุมคำขอต่อ IP แบบ In-Memory ใน app/core/rate_limit.py ป้องกัน DoS และการยิงเรียก LLM API สิ้นเปลือง
  • JWT Authentication: Access Token อายุ 15 นาที, Refresh Token อายุ 7 วัน รหัสผ่านเข้ารหัสด้วย Bcrypt ผ่าน Passlib
  • Database Connection Pooling: กำหนด pool_size=10, max_overflow=20, pool_recycle=3600, pool_pre_ping=True ป้องกัน Connection หลุด
  • Input Sanitization: ป้องกัน Path Traversal ด้วย safe_filename() และป้องกัน Stored XSS ในประกาศด้วย sanitize_html() ก่อนบันทึก DB เสมอ

ข้อที่ หมวดหมู่นโยบาย ISO ประเด็นคำถามและสาเหตุ แนวทางแก้ไขเชิงระบบที่แนะนำ
